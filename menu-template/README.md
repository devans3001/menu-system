# Menu Template (engine)\n\nOne shared menu engine, duplicated per restaurant. Skin and identity live in `restaurant.config.ts`. Menu and billing state live in Neon in production. Local demo runs from `lib/data/seed.ts` with no database. See `design.md` for the demo skin brief and `schema.sql` for the Neon tables.\n\nRun: `npm install`, then `npm run dev`. Guest view at `/`, owner editor at `/admin` (demo mode, no real email sent).\n
